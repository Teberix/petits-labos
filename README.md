# Petits Labos

A small offline educational game hub for young children (PWA). Plain HTML/CSS/JS,
no build step, no network calls, no tracking — all progress stays on the device.

- Run locally: `node tools/serve.mjs` → http://localhost:8080/petits-labos/
- Install: open the GitHub Pages URL in Chrome on Android → menu → *Add to Home screen*.

See `CLAUDE.md` for architecture and the release routine.
